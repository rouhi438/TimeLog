# TimeLog update
Copy the existing .env.local into this project locally (never commit it). Run npm ci, npx tsc --noEmit, npm run build, npm run dev. Existing Neon JSON records are compatible; no SQL migration is necessary. Old records without start/end keep their original hours. New entries use minute-accurate times; overnight shifts are attributed to their starting date. Historical bulk input accepts decimal hours or start/end. Test with fictional records, including 15:20–21:45, 23:30–01:00 next day, edit, CSV, PDF, calendar and yearly report. Verify both managers and unauthenticated/unauthorized API requests before real data. Full dependency build and live Neon tests were not performed in the generation environment.
